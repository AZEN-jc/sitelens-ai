审查日期：2026-10-28。审查对象为当前 `main` 应用及本轮修复后的工作树；预期场景是本机单用户、低并发。审查覆盖 Vue 页面和路由、FastAPI、URL/DNS 与网络传输、响应解析、规则匹配、SQLite、历史比较、报告、AI、安全配置、启动/构建和测试。

## 结论

发现并修复了历史列表在 30 条后无法继续查看的问题；设置页关键按钮现在也有组件交互回归测试。后端、Ruff、前端测试和生产构建均通过，并用新版本服务验证了页面/API 深链和分页接口。

在本次检查和测试覆盖的范围内，没有发现已复现的扫描目标安全绕过、完整网页落库或 API Key 写入数据库问题。此结果不是形式化安全证明，也没有对真实外部网站发起请求。

## 本轮修复

### 历史超过 30 条后不可用 — 已修复

原先 `/api/scans` 只返回最近 30 条，比较与报告页面没有加载更多入口，旧记录虽然仍在 SQLite 中，却无法从这些页面选择。现在列表 API 接受 `limit` 和 `offset`，新增 `/api/scans/count` 返回总量；比较和报告页面按 30 条逐页加载，首页记录数使用真实总数。扫描按创建时间和 ID 倒序，保证同一时间戳时顺序稳定。

回归测试创建 35 条本地记录，确认总数为 35，第一页 30 条，第二页 5 条，两页覆盖全部 ID。前端组件测试确认比较选择器和报告列表加载旧记录后到达 35 条并隐藏“加载更多”。

### 设置操作缺少测试 — 已补齐

设置页组件测试实际驱动保存配置、确认保存后密钥输入清空、连接失败提示和清除配置后的状态刷新。它覆盖 Vue 组件与 API 边界；本轮没有真实浏览器自动化，所以仍未做鼠标/键盘视觉点验。

## 审查到的安全与数据路径

- 扫描只调用普通 GET。`validate_target` 限定 HTTP(S)、拒绝 URL 凭据，并拒绝任何私网/本机/保留 DNS 地址；`PinnedBackend` 连接校验过的 IP，`fetch_page` 手动跟随重定向并逐跳重验，客户端设置 `trust_env=False`。超时、重定向数及响应体大小均有限制。
- 响应解析只选取有限响应头、Meta、标题和脚本/样式资源 URL；完整 HTML 只在本次内存流程中用于匹配。数据库存摘要、技术、证据和用户主动请求生成的 AI 报告。
- 检测结论包含具体命中证据；规则分数封顶，比较中的缺失项写作“本次未观察到”。
- AI Base URL 与扫描目标使用独立信任规则。密钥通过 `SecretStr` 接收，留在服务内存；测试确认其不返回给前端、不会进入报告历史，生成文本也会移除完整密钥回显。
- HTML 报告转义网页标题、规则命中内容、AI 内容和模型名。前端通过 Vue 插值呈现不可信数据，没有发现 `v-html`。
- 服务绑定 `127.0.0.1` 且没有账号认证，只适合本机单用户，不应暴露到共享网络。

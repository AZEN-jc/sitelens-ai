# 毕业设计说明书素材

## 建议摘要

本课题设计并实现 SiteLens AI 网站技术特征识别与分析系统。系统使用 Python 与 FastAPI 获取授权网站公开 HTTP 信息，通过可扩展的 JSON 指纹规则识别常见 Web 技术，并将匹配来源和值保存为证据。用户可查看技术类别、置信等级、历史差异和报告；可选的 OpenAI 兼容接口只根据结构化检测结果生成解释，不参与技术存在性判定。系统采用 Vue 3、TypeScript 与 SQLite，可在本机完成演示。为降低访问风险，系统限制协议、DNS 解析地址、重定向次数、请求时间和响应大小，并避免保存完整网页或 AI 密钥。

## 章节建议与写作重点（约 2000–2200 字）

1. **绪论（约 250 字）**：说明网站技术栈不透明带来的学习、维护与调研需求；限定为公开信息识别，不进行漏洞探测。
2. **相关技术（约 350 字）**：介绍 Python、FastAPI、HTTPX、BeautifulSoup、Vue、SQLite 和 OpenAI 兼容接口。
3. **系统设计（约 450 字）**：描述前后端结构、检测流程、四类数据库记录、私网拦截和 API Key 内存生命周期。
4. **系统实现（约 550 字）**：重点说明多来源规则匹配、权重封顶与置信等级、证据追溯、AI 只解释不判定、历史比较的“不代表移除”语义。
5. **系统测试（约 250 字）**：使用本仓库的 React 与 WordPress 可控页面，报告本轮自动化测试命令和真实结果；分开写功能测试与安全边界测试。
6. **总结（约 150 字）**：总结本地产品流程和局限，说明动态渲染、覆盖率和统计校准可作为未来研究，不将其写成已实现能力。

提交学校前，应把测试数字替换为 `docs/TEST_REPORT.md` 中最新实际结果，并按学校模板与字数要求编辑。

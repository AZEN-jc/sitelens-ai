# 出镜实操视频分镜表 [实测 Measured]

> 适用类别为实践操作类。时长按 20 分钟设计，可拉长到 30 分钟。
> 全文按当前仓库真实流程校正。原方案中的「勾选授权」与「顶部姓名横幅」均已删除。
> 台词里的四项个人信息在提交前替换。个人标识实际出现在导出报告页脚。

## 录制前准备

- 执行 `./scripts/start.sh`，确认浏览器打开 `http://127.0.0.1:8000`。
- 执行 `./scripts/verify-all.sh`，把全绿输出留在终端窗口备用。
- 预置的离线演示记录共 8 条，包含 2 条仿真样本与 6 条真实网站记录。
- 摄像头放在屏幕右下角，界面字号放大到 125%，保证录制可读。
- 把 `docs/DEMO_SCRIPT.md` 放在手边作为提词卡。
- 机房缺 Node.js 或 uv 时改用零依赖离线包。命令是 `python3 scripts/serve-offline.py`，端口为 8010。此时跳过 02:30 至 05:30 的验收脚本段，改为展示 `demo` 目录里的界面快照与数据快照。

## 录制注意

- 现场检测环节建议准备第二个目标网站备用。个别站点在本机直连下可能超时。
- 超时不是程序缺陷。可以顺势讲禁用代理的防 SSRF 设计。
- 若现场完全断网，跳过第 12:30 至 15:00 段，其余环节都能用离线演示数据完成。
- 报告中出现的 `【填写姓名】` 等占位符，提交前必须先替换。
